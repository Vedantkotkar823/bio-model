# SPIDER SILK-INSPIRED FIBERS: ULTRA-LIGHTWEIGHT BULLETPROOF VESTS & BIODEGRADABLE SURGICAL SUTURES

> **First-Year Engineering College Project Exhibition**  
> **Interactive Digital Science Poster & 15-Section Guided Exhibition System**

---

## 🔬 Project Overview

This project is a premium, interactive digital science poster website engineered for a college science symposium where **15 engineering students present for approximately 3 minutes each** across 15 dedicated technical sections.

Departing from conventional text-heavy academic boards, this poster delivers a cinematic, visual-first storytelling experience (**~70% visuals, ~30% concise text**) explaining how the remarkable properties of natural spider dragline silk inspire two cutting-edge engineering applications:

1. **Ultra-Lightweight Protective Vests:** Multi-layer kinetic energy dissipation, high work-to-fracture (~160 MJ/m³), ergonomic flexibility, and blunt-force trauma reduction under NIJ Standard-0101.07.
2. **Biodegradable Surgical Sutures:** Ultra-fine microsurgical approximation, natural enzymatic breakdown into benign amino acids, and synchronized wound-healing tensile retention without secondary surgery.

## 🎨 Upgraded Interactive Visual Design System

- **Every Visual is Interactive:** Every major image and diagram across all 15 sections features interactive pulsating radar hotspots, click-to-explore cutaways, and zoom inspection.
- **Microscopic Fiber Cross-Section Explorer:** Interactive 3-level zoom from macroscopic strand ($20\,\mu\text{m}$) down to $\beta$-sheet nanocrystals ($2\text{--}5\,\text{nm}$) and amorphous glycine coils.
- **Dynamic Tensile Loading & Strain Simulator:** Interactive slider applying tension ($0\text{ to }1.5\,\text{GPa}$), demonstrating Poisson thinning, force vector arrows, elastic vs. plastic yield regimes, and live energy absorption ($165\,\text{MJ/m}^3$).
- **3-Layer Protective Vest Cutaway Inspector:** Strike-face, intermediate 3D orthogonal energy core, and backing trauma layer with animated acoustic wave dispersion rays ($c = \sqrt{E/\rho} \approx 3,200\,\text{m/s}$).
- **Biodegradable Suture Tissue Closure Simulator:** Interactive knot tension slider tightening wound margins, collagen bridge synthesis, and 60-day in vivo enzymatic bio-resorption timeline.
- **6-Stage Biomimicry Manufacturing Flow:** Step-by-step interactive pipeline from spider silk in nature to recombinant fermentation, microfluidic wet-spinning, and post-draw alignment.
- **Background:** Midnight navy and pitch black (`#020408`, `#050a14`, `#081021`)
- **Protective & Synthetic Fiber Accents:** Iridescent cyan & electric blue (`#00f0ff`, `#38bdf8`)
- **Natural Spider Silk Accents:** Warm amber and golden filaments (`#f59e0b`, `#fbbf24`)
- **Biomedical & Sustainability Accents:** Soft emerald green & mint (`#10b981`, `#34d399`)

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18 or higher recommended; tested on v24.20.0 LTS)
- npm (v9 or higher; tested on v11.19.0)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser to: **`http://localhost:3000`**

### 3. Build for Production
```bash
npm run build
npm run preview
```

## 🧪 Interactive Science Modules

1. **Interactive Spider Web Dew & Tension Simulator:** Canvas rendering of radial dragline stiffness and viscid spiral sag with wind oscillation controls.
2. **Dynamic Tensile Loading & Strain Energy Simulator:** Real-time tension slider (0 to 1.5 GPa), Poisson thinning, force vector arrows, elastic/plastic uncoiling, and work-to-fracture energy absorption integral.
3. **Microscopic Fiber Cutaway & Molecular Architecture Explorer:** 3-level interactive zoom from macroscopic strand ($20\,\mu\text{m}$) down to $\beta$-sheet nanocrystals ($2\text{--}5\,\text{nm}$) and amorphous glycine coils.
4. **Interactive Stress–Strain Schematic Kinetic Graph:** Real comparative curves for Spider Dragline Silk, Kevlar 29, High-Tensile Steel Wire, Nylon 6,6, and Carbon Fiber, displaying ultimate tensile strength ($\text{GPa}$), elongation at break ($\%$), and shaded work-to-fracture area ($160\,\text{MJ/m}^3$).
5. **Multi-Layer Ballistic Textile Cutaway Inspector:** Strike-face, intermediate 3D orthogonal energy core, and backing trauma layer with animated acoustic shockwave vectors.
6. **Kinetic Impact Shockwave Simulator:** Interactive 2D woven orthogonal mesh dissipating a 220-joule impact via transverse acoustic wave propagation ($c = \sqrt{E/\rho}$).
7. **Surgical Suture Wound Closure & In Vivo Resorption Simulator:** Interactive knot tension slider tightening dermal wound margins, collagen matrix synthesis, and 60-day in vivo enzymatic bio-resorption timeline.
8. **6-Stage Biomimetic Manufacturing Pipeline:** Step-by-step interactive walkthrough of genetic sequencing, recombinant fermentation, microfluidic wet-spinning, and post-draw mechanical alignment.
